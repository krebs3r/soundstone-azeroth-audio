# Soundstone 0.2.0 — validation build

- Custom Retail and Classic frames derived from the approved mockup, with separate corners, a red close button, six grip dots and diamond slider thumbs.
- Proportional icons with true transparency; compact 300 × 45 and expanded 300 × 160 layouts.
- Shared position and mutually exclusive views, a grip/title menu, and layered Escape behavior.
- Additional 75–150% size control that follows WoW's UI scaling. Existing bar position and visibility migrate automatically.
- WoW game-output device selection with refreshed device lists, stale-device checks and one audio-system restart per successful change. Channel volumes and mute settings remain untouched.
- German and English instructions, including the author's second-monitor streaming use case.
- 126 automated Lua scenario checks, including device errors, view migration and simulated scale/resolution combinations.

In-game visual acceptance, audible device switching and full client coverage remain release gates. This build does not establish pixel-for-pixel parity or verified support for every target client. See [TESTING.md](TESTING.md). WoW: Forever remains unverified.
