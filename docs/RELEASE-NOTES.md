First functional release of Soundstone – Azeroth Audio.

- Master, effects and music toggles, sliders and percentages.
- Movable compact bar and minimap button; optional key bindings.
- Retail/Classic frame styling, custom icons, German and English UI.
- Native WoW CVar synchronization; preserved volumes while muted.
- Automated Lua 5.1 coverage with simulated API/client configurations.

This prerelease targets Retail, Mists Classic, TBC Anniversary and Classic Era. See TESTING.md for actual in-game validation status. WoW: Forever is unverified.
