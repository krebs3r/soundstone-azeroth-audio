# Soundstone 0.3.0

- Compact audio bar and expanded mixer with English and German controls.
- Unified master, music and sound-effects toggles, preserving volume when muted.
- Sound effects controls effects, ambience and dialogue together; voice chat remains separate.
- Restores the last positive volume when enabling a channel at zero.
- Attached output-device dropdown with validated selection and error reporting.
- Smaller options, matching header buttons, optional overlap avoidance when placing the UI, and shorter tooltips.
- Paged release notes opened by clicking the version footer.

Open with `/soundstone`. See the game versions on this file for the clients covered by in-game acceptance. This is the first CurseForge distribution of version 0.3.0.
