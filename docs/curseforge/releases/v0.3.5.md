# Soundstone 0.3.5

- The minimap button now has the same size as other addons' buttons (e.g. Hourstone or LibDBIcon buttons). Its dark background no longer reaches past the ring.

## Deutsch

- Der Minimap-Button hat jetzt dieselbe Größe wie die Buttons anderer Addons (z. B. Hourstone oder LibDBIcon). Der dunkle Hintergrund ragt nicht mehr über den Ring hinaus.
